# Project Charter

## Project name
Digital Learning Program Launch

## Objective
Launch a paid 4-week online learning program with a complete learner experience, functioning checkout, approved content, and all launch assets ready before the target release date.

## Business goal
Create a new revenue-generating education product while giving learners a smooth experience from purchase through onboarding and course participation.

## In scope

- Curriculum and lesson materials
- Sales / landing page
- WooCommerce product setup
- Checkout testing
- LearnDash course setup
- Video upload and embedding
- Email launch sequence
- Learner onboarding emails
- Affiliate / partner assets
- QA and launch-readiness review
- Post-launch retrospective

## Out of scope

- Full website redesign
- New CRM implementation
- Paid media management
- Major platform migration
- Rebuilding the full brand identity

## Core stakeholders

| Role | Responsibility |
|---|---|
| Project Manager | Planning, coordination, tracking, risk management, reporting |
| Product Lead | Business decisions and final scope approval |
| Subject Matter Expert | Curriculum and content accuracy |
| Copywriter | Landing page and email copy |
| Designer | Visual assets |
| Video Editor | Lesson and promo video editing |
| Web / LMS Specialist | WordPress, WooCommerce, LearnDash setup |
| Marketing Lead | Campaign execution |
| QA Reviewer | Final launch checks |

## Project manager responsibilities

- Create the project plan
- Define milestones and dependencies
- Assign and track owners
- Run weekly status meetings
- Surface blockers early
- Keep scope visible
- Coordinate QA
- Maintain risk and decision logs
- Confirm launch readiness
- Run post-launch retrospective

## Definition of done

The project is complete when:

- All launch-critical content is approved
- Checkout and access flows have been tested
- Learner onboarding is ready
- All launch emails are scheduled
- Video and course assets are published
- No critical QA issues remain open
- Launch approval is documented
